# 设计规范清单（Design Spec）

> 供 UI 设计师 / 前端对接使用，与《UI视觉稿.html》一致。

## 1. 品牌色

| 角色 | 色值 | 用途 |
|---|---|---|
| Primary 主色 | `#6C4CF1` | 主按钮、选中态、品牌强调 |
| Primary 2 | `#5A8BFF` | 渐变过渡色 |
| Accent 强调 | `#FF8A5C` | 次要强调、角标（少用） |
| Gold 金色 | `#F5B84B` | 点缀、奖励类标识 |
| Dark 深背景 | `#15151E` | 试戴页/相机区背景 |
| Light 浅背景 | `#F7F6FB` | 页面底、卡片底 |
| Text 主文字 | `#1C1C28` | 标题、正文 |
| Text 次文字 | `#8A8F9C` | 辅助说明、占位 |

主按钮渐变：`linear-gradient(135deg, #6C4CF1, #5A8BFF)`，阴影 `0 8rpx 32rpx rgba(108,76,241,.35)`。

## 2. 字体

| 层级 | 字号 | 字重 | 用途 |
|---|---|---|---|
| 大标题 | 60rpx | 800 | 首页主文案 |
| 页面标题 | 40rpx | 700 | 结果标题、弹层标题 |
| 正文/按钮 | 30–32rpx | 600 | 按钮、列表项 |
| 辅助说明 | 24rpx | 400 | 标签、提示 |

字体栈：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`。

## 3. 圆角与间距

- 卡片圆角：32rpx；按钮圆角：28rpx；缩略图圆角：24rpx。
- 页面左右留白：32rpx；面板内留白：32rpx。
- 元素间距：色板 20rpx、发型卡片 24rpx、弹层内 24rpx。

## 4. 核心组件

| 组件 | 规格 |
|---|---|
| 主按钮 | 渐变底、白字、圆角 28rpx、高 96rpx、按压缩放 |
| 次按钮 | 白底、描边 `#DCDCE4`、圆角 28rpx |
| 发型卡片 | 116rpx 方块、圆角 24rpx、emoji 居中，选中态紫描边 4rpx + 浅紫底 |
| 发色色板 | 64rpx 圆点、白描边 + 灰环，选中态紫环 5rpx |
| 对比卡片 | 圆角 24rpx、浅底、图 + 顶部标签 |
| 弹层 | 全屏遮罩 `rgba(20,20,30,.7)`，卡片圆角 40rpx |

## 5. 页面与状态

| 页面 | 关键点 |
|---|---|
| 首页 | 渐变底（白→浅紫）、品牌名 + 主文案 + 主按钮 |
| 授权 | 权限卡片（图标 + 标题 + 说明）、用途说明块、拒绝/同意按钮 |
| 试戴 | 深色相机区 + 底部白面板（发型横滑 / 发色色板 / 拍照按钮）、顶部栏 + 实时标签 |
| 生成中 | 加载动画 + 文案 + 进度条 |
| 结果 | 原图/效果图对比 + 保存/分享/再试一次 |

**状态态**：未检测到人脸 → 顶部引导文案「请正对屏幕，保持光线充足」；生成中 → 按钮 loading；失败 → toast「生成失败，请重试」；无相册权限 → 引导去设置。

## 6. 图标与 emoji

- 发型缩略图暂用 emoji 占位（💇‍♀️ 短发 / 💁‍♀️ 长发 / 👩‍🦱 卷发 / 👩‍🦲 清爽），正式上线替换为真实发型缩略图 PNG。
- 功能图标：💾 保存、🔗 分享、↺ 再试。
