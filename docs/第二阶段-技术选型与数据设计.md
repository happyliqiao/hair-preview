# 第二阶段：技术选型、数据设计与交互原型

> 承接《需求分析与实施计划》。本文给出可直接落地的技术决策、云数据库表结构和交互线框。
> 已定默认值：前端 = 原生小程序；第一期 = 15 款发型、16 种发色。

---

## 1. 技术选型明细

### 1.1 前端框架：原生小程序（结论）

| 方案 | 结论 | 理由 |
|---|---|---|
| **原生小程序** | ✅ 采用 | VKSession / WebGL / camera / 云开发 SDK 全部是微信原生能力，接入最直接、文档与官方示例最全；本项目核心是「重前端实时渲染」，原生最稳、性能最可控。 |
| uni-app / Taro | ❌ 暂不 | 需要跨端或团队强依赖 Vue/React 才考虑；其 WebGL 与 VKSession 的桥接成熟度不如原生，调试成本更高。 |

> 若团队只熟 Vue/React，可评估 Taro，但需先做「VKSession + WebGL」的可行性小样（spike）再定。

### 1.2 AR 实时渲染方案（两套 + 降级链）

**主方案 · VKSession face 模式 + 自定义 WebGL**
- `wx.createVKSession({ track: { face: { mode: 1 } } })` 启动前置人脸跟踪。
- `vkSession.on('update', vkFrame => { ... })` 每帧回调。
- `vkFrame.getCameraTexture()` 取相机纹理（作为 WebGL 背景）。
- `vkFrame.getFaceMesh()` 取人脸 3D 网格顶点（用于对齐发型贴图、推算头发色罩区域）。
- 在 WebGL canvas 上依次绘制：相机纹理 → 发色色罩 → 发型 PNG 贴图。

**降级方案 · camera 组件 + 2D canvas（静态模式）**
- 能力探测：`wx.createVKSession` 不可用/启动失败时自动降级。
- `camera` 组件取前置画面 + `wx.faceDetect` 对单帧做静态人脸关键点检测。
- 用 2D canvas 把发型贴图按关键点仿射对齐叠加（不能逐帧实时，改为「对准后锁定」体验）。

**降级链**：VKSession 成功 → 实时模式；失败 → camera 组件 + 静态对齐模式（保证所有机型可用）。

### 1.3 发型贴图对齐方案
- 用「额头中心、左右太阳穴、鬓角」作为锚点，把发型 PNG 的锚点与真人关键点做**仿射变换**（平移 + 缩放 + 旋转）。
- 发型素材必须按**统一基准**制作：同一画布尺寸、同一锚点坐标、透明背景、正面视角。
- 产品层做「请正对屏幕」的取景引导，正面效果优先，接受侧脸/转头时贴合度下降。

### 1.4 发色色罩方案（实时段近似）
- 基于人脸网格外扩得到「头部 + 头发」大致区域（椭圆/多边形）。
- 叠加半透明色块，配合 WebGL 混合模式（如 `multiply` / `soft-light`）与可调浓度，达到「大概发色」效果。
- 精确发色交给 AI 精修段完成。

### 1.5 AI 精修集成方案（腾讯云人脸融合 FaceFusion）

- **流程**：拍照 → `wx.cloud.uploadFile` 传原图到云存储 → 云函数调 FaceFusion（顾客照片 + 目标模板）→ 结果图存云存储 → 返回链接回显。
- **模板化**：每个「发型 × 发色」组合对应一个 FaceFusion 模板（`template` 集合维护映射）。
- **异步与结果返回**：第一期用**前端轮询**（每 2s 查一次 `generation` 状态），二期可换订阅消息。
- **密钥管理**：SecretId/SecretKey 放云函数**环境变量**，不硬编码、不进前端。

### 1.6 云开发结构总览

| 资源 | 内容 |
|---|---|
| 云函数 | `getCatalog`（发型/发色/模板列表）、`genHairstyle`（调 FaceFusion）、`getGenResult`（轮询结果）、`cleanupTempPhoto`（定时删临时原图，合规用） |
| 云存储 | `/hairstyles/`（实时 PNG）、`/templates/`（融合模板图）、`/user-photos/`（临时原图，用后即删）、`/results/`（效果图） |
| 云数据库 | `hairstyle` / `hairColor` / `template` / `generation` / `config`（详见第 2 节） |

## 2. 云数据库表结构设计

### 2.1 `hairstyle` 发型目录

```js
{
  _id: "auto",
  name: "齐肩梨花烫",              // 显示名
  category: "烫发",                // 短发/长发/烫发/卷发/直发
  thumbnailUrl: "cloud://.../hairstyles/thumb_01.png",  // 列表缩略图
  overlayUrl:   "cloud://.../hairstyles/overlay_01.png",// 实时 AR 用的透明 PNG
  sortOrder: 1,
  enabled: true,
  createdAt: 0, updatedAt: 0
}
```

### 2.2 `hairColor` 发色目录

```js
{
  _id: "auto",
  name: "焦糖棕",
  hex: "#8A5A2B",                 // 展示色值
  tintHex: "#8A5A2B",             // 实时色罩用色
  tintOpacity: 0.45,              // 色罩浓度
  sortOrder: 1,
  enabled: true,
  createdAt: 0, updatedAt: 0
}
```

### 2.3 `template` FaceFusion 融合模板（发型 × 发色组合）

```js
{
  _id: "auto",
  hairstyleId: "hair_01",
  colorId: "color_03",            // 可空 = 通用模板
  facefusionModelId: "qc_xxx",    // 腾讯云侧模板/项目标识
  previewUrl: "cloud://.../templates/tpl_01_03.jpg",
  enabled: true,
  createdAt: 0, updatedAt: 0
}
```

### 2.4 `generation` 生成记录（轮询 + 历史）

```js
{
  _id: "auto",
  _openid: "oXxx",               // 云开发自动写入，顾客身份
  hairstyleId: "hair_01",
  colorId: "color_03",
  photoFileId: "cloud://.../user-photos/xxx.jpg",  // 临时原图
  resultFileId: "cloud://.../results/xxx.jpg",      // 结果图
  status: "processing",          // pending | processing | success | failed
  errorMsg: "",
  createdAt: 0, finishedAt: 0
}
```

### 2.5 `config` 全局配置

```js
{
  _id: "auto",
  key: "shareTitle",             // 分享文案、是否开启AI、catalog版本等
  value: "看看我做完发型长啥样~"
}
```

> 说明：第一期**不强制登录**，`_openid` 由云开发自动生成，够做「生成记录 + 历史」。`user` 表（昵称头像、收藏、会员）留到需要时再加。

## 3. 交互原型（页面流程 + 线框）

### 3.1 页面地图

```
[首页/引导] → [授权] → [试戴页(核心)] → [生成中] → [结果页]
    │                        │                       │
    │                        └── 发型横滑 / 发色色板 / 拍照
    │                                                └── 保存相册 / 分享 / 再试一次
```

共 5 个页面，均为单页（原生小程序用 1 个页面 + 状态切换，或拆 2~3 个 page，建议 MVP 用**单页状态机**，减少跳转与授权中断）。

### 3.2 页面线框

**① 首页/引导**
```
┌──────────────────────┐
│   (品牌/门店名)        │
│                      │
│   🎨 一秒预览          │
│   你的新发型新发色      │
│                      │
│   ┌────────────────┐  │
│   │  开始试戴 →      │  │
│   └────────────────┘  │
│   使用前需授权摄像头    │
└──────────────────────┘
```

**② 授权（弹窗/页）**
```
┌──────────────────────┐
│  需要以下权限          │
│  [📷] 摄像头          │
│  [😀] 人脸信息(试戴用)  │
│  ── 用途说明：仅为     │
│  试戴效果，生成后即删   │
│  [ 拒绝 ]  [ 同意并授权 ]│
└──────────────────────┘
```

**③ 试戴页（核心）**
```
┌──────────────────────┐
│  ⟵    ✨ 试戴中        │
│ ┌──────────────────┐ │
│ │   (前置摄像头画面)  │ │
│ │    👤 ← 发型贴图    │ │
│ │    🎨 ← 发色色罩    │ │
│ │  "请正对屏幕"      │ │
│ └──────────────────┘ │
│ 发型: [🅰][🅱][🅲][🅳]→  │
│ 发色: ● ● ● ● ● ● ●  │
│ ┌──────────────────┐ │
│ │   拍照生成效果图     │ │
│ └──────────────────┘ │
└──────────────────────┘
```

**④ 生成中**
```
┌──────────────────────┐
│        ◠             │
│   正在生成效果图...     │
│   通常几秒~十几秒       │
└──────────────────────┘
```

**⑤ 结果页**
```
┌──────────────────────┐
│  原图      vs      效果│
│ ┌──────┐ ┌──────┐   │
│ │ 原图  │ │ 效果图 │   │
│ └──────┘ └──────┘   │
│ ┌────────────────┐   │
│ │   💾 保存到相册    │   │
│ ├────────────────┤   │
│ │   🔗 分享给好友    │   │
│ └────────────────┘   │
│   [ 再试一次 ]        │
└──────────────────────┘
```

### 3.3 关键交互状态
- **未检测到人脸**：提示「请正对屏幕 / 调整光线」，不做叠加以免错位。
- **拒绝授权**：友好说明用途，提供「去设置开启」入口。
- **AI 超时/失败**：显示失败原因 + 「重试」按钮，不卡死。
- **保存相册拒绝**：提示去系统设置开启相册权限。
